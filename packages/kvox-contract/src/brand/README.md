# brand

The KVox identity values, colour tokens and logo geometry, shared by the web theme and the API's document exporters.

## Purpose and scope

The one source of the KVox look that is not React: `KVOX_IDENTITY` (product name, tagline and the two colours of `packages/shared/identity.json`), `BRAND_TOKENS` (the light and dark palettes), the `MARK_*` geometry of the logo and `brandMarkSvg()`, which draws that geometry as a standalone SVG string. `@marinoscar/kvox-web/brand` builds the MUI theme and `BrandMark` on it; `@marinoscar/kvox-api` derives the print palette and the PDF/Word logo from it. Plain data and string functions: no Node built-in, no framework, so it loads in the browser too.

- `identity.generated.ts`: `KVOX_IDENTITY`, `KvoxIdentity`. GENERATED by `packages/kvox-web/scripts/sync-brand-identity.mjs` (`npm run brand:sync -w @marinoscar/kvox-web`); never edit by hand.
- `tokens.ts`: `BRAND_TOKENS`, `PaletteMode`.
- `mark-geometry.ts`: `MARK_*` constants, `MarkRect`, `MarkLine`.
- `mark-svg.ts`: `brandMarkSvg`, `BrandMarkSvgOptions`.

Status: experimental.

## Entry point

`@marinoscar/kvox-contract/brand`. The slice depends on no other slice.

## Peer dependencies

None. The slice imports no other package.

## Configuration

None. A rebrand rewrites `packages/shared/identity.json` and re-runs the sync script; `npm run brand:check -w @marinoscar/kvox-web` fails on drift.

## Extension-point catalog

None. The slice exposes data and pure functions, not extension points.
