The graph explorer, the whole-graph overview and the entity page's neighbourhood widget now draw with AntV G6 5 (`@antv/g6`, Canvas renderer) instead of sigma (#775). `@antv/g6` replaces `sigma`, `@react-sigma/core`, `@sigma/edge-curve`, `@sigma/node-border`, `@sigma/node-image`, `graphology-layout-forceatlas2` and `graphology-layout-noverlap` as the optional peer of `graph/ui`; `graphology` stays (the models). G6 is about 410 KB gzipped and stays in the lazily loaded canvas chunk, so `graph/headless` and `graph/ui` load without it.

`GraphCanvasProps` and `GraphCanvasControls` keep their shape; two optional props are new: `minimapContainer` (the element G6's minimap draws into, which `ExplorerMinimap` now renders as a frame) and `showZoomControls`. The canvas adds an on-screen zoom cluster (zoom in, zoom out, fit, full screen where the Fullscreen API exists; 44px targets on a coarse pointer), fits the visible nodes with 48px padding after the first draw and after each layout until the user moves the camera, and clamps the zoom to 0.1 to 6. Nodes are 18 to 56px discs (items are rounded rectangles) with a centred pictogram, a label on a paper-coloured pill and a count badge on a "+N more" stub; edges are quadratic arrows 1.25 to 5px wide, coloured by relation family (`relationFamily`, `RELATION_FAMILY_COLORS`) and dashed when derived or resistant. Hover, preview, selection, seed, pin, path, marks and the user's own node (`isSelf`) are G6 element states computed from the existing reducers; below zoom 0.6 only the labels that matter stay.

Layouts run on the main thread and never set `enableWorker` (the CSP forbids `blob:` workers): `forceatlas` is an incremental `d3-force` (laid-out nodes fixed with `fx`/`fy`, only new ones move, time-boxed by iterations), `concentric` a `radial` around the first seed, `static` none. The ForceAtlas2 worker and its client (`layoutEngine`, `layout.worker`, `layoutClient`, `protocol`, `tween`, `incremental`, `concentric`, `useCanvasLayout`) are removed, as are `FA2_SETTLE_ITERATIONS` (now `FORCE_SETTLE_ITERATIONS`) and `capPixelRatio` (now `cappedPixelRatio`, passed to G6 as `devicePixelRatio`). The lasso no longer depends on the renderer. The drawing-surface probe (`isWebGLAvailable`) now checks for a 2D canvas, since G6 needs no WebGL.
