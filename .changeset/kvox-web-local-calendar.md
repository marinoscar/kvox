The explorer and the review queue follow the user's calendar. The TimeBar, its presets and the as-of slider work in calendar days of the display time zone (the zone the API now cuts graph activity in): today is the local day, weeks start on the local Monday, day arithmetic runs on date keys (DST-safe), "Last 30/90 days" and "Last year" end at the local tomorrow, and an instant shown in the TimeBar lands in the bucket of its local day. `GraphActivityResponse` gains the required `timeZone` the API echoes. Start here's `since` is the local day 30 days back; a relation saved with an empty "Since" still sends no `validFrom` (the server uses the requester's today). An import group's heading formats the key's `createdAt` in the display zone when present. `formatRelativeTime` counts days on the local calendar ("yesterday" is the previous local day) and takes an optional zone. New `timeAxis` helpers: `dayKeyOf`, `todayDay`, `todayKey`, `addDaysToKey`; `presetRange`, `presetOf`, `timeControlLabel`, `rangeForInstant`, `monthSteps`, `sinceDate` and `reviewGroupLabel` take an optional IANA zone (default the display zone). `parseAsOfParam` rejects an impossible date such as `2026-02-31`.
