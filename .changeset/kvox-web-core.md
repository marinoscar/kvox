Add `@marinoscar/kvox-web/core/headless`, `/core/ui` and `/core/testing`, and `/transcription/headless` and `/transcription/ui`, replacing the empty `./core` scaffold entry. `core/headless` is the host port every web slice reads (`KvoxWebHost` with its HTTP, event-stream and optional upload transports, `KvoxWebHostProvider`, `useKvoxHost`, `useKvoxViewer`, `useHasPermission`), `KvoxApiError`, the `kvox*` request helpers, `connectKvoxSse` (reconnect with backoff and `Last-Event-ID` resume), the resumable upload engine, `useVisiblePolling`, and the domain-neutral hooks and helpers the slices share (relative time, the feed cache and reconciler, scroll restoration, the clipboard, the wake lock). `core/ui` carries the library chrome and the `KvoxSettingsCard`, `KvoxDestination` and `KvoxRouteDef` types a slice exports its settings cards, destinations and routes with. `core/testing` carries `createFakeKvoxWebHost`, `renderWithKvoxHost`, a fake `XMLHttpRequest` and `describeKvoxWebConformance`. The transcription slice moves the admin page, client and hook of `/admin/settings/transcription` into the package, with its card and route as data and a `renderSecretField` slot for the API key control. `@mui/material`, `@mui/icons-material`, `react-router-dom` and `@testing-library/react` stay optional peers: a host that uses only the headless entries installs none of them.
