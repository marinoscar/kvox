The graph explorer renders through a responsive Insight Canvas shell (GIC-08, #669, epic #661). `InsightCanvasLayout` (internal to the explorer, in `graph/ui/components/explorer/shell/`) has the slots `topBar`, `facets`, `canvas`, `inspector` and `timeBar` and adapts by window class (compact below 600, medium 600 to 1199, expanded from 1200, read by the package's own `useWindowClass`) and by input (`useInputModality`, `(pointer: coarse)` or `(hover: none)`, independent of the width). Compact: the inspector is a bottom sheet with peek, half and full snaps (drag, tap, keyboard, Escape, focus in and back to the canvas) and the filters a left drawer behind a Filters button. Medium: a 56px icon-chip rail whose chip opens the filters in a popover, and the inspector as a closable 360px right overlay, with the canvas panning the selection out from under it. Expanded: three panes with keyboard-operable separators (facets 220 to 400px, inspector 300 to 520px, collapsible), their widths and collapse state persisted per user and window class in `localStorage` (every access in `try/catch`). The canvas is never remounted by a class change, so a rotation keeps the camera, the selection and the inspector. Touch: the first tap on a node previews it, the second opens the inspector; a 500ms long-press (haptic tick where available) opens a node menu (Open details, Expand, Pin, Hide, Make seed); pinning is long-press then drag; "Select" mode in the top bar marks nodes by tapping; the canvas alone takes `touch-action: none`; a coarse pointer gets a 44px pick radius. `explorerBudgets` holds the budgets: 120 visible nodes on a compact window or coarse pointer (300 otherwise, the existing `EXPLORER_NODE_CAP`), a 1.5s or 3s layout time box, a `devicePixelRatio` cap of 2, `hideEdgesOnMove` above 500 or 1,000 edges and reduced label density. `useGraphExplorer` takes `nodeCap`, `ExplorerState` carries `cap`, `CapWarning` takes `cap`, and `GraphCanvas` takes `previewId`, `markedIds`, `inputModality`, `budgets`, `revealInsets` and `onNodeContextMenu` (all optional, so the overview is unchanged) and its controls gain `getCamera` and `setCamera`. On a compact window the list view is the default for a graph over 120 nodes; `view=graph` overrides it. `ExplorerSidePanel` now renders inline inside the inspector slot (it reads no breakpoint; it is a named group, not a landmark); `ExplorerToolbar` keeps the view controls and a new `ExplorerFilters` holds the filters. Respects `prefers-reduced-motion` (no sheet animation) and the safe-area insets. The five platform shell breakpoint gates are untouched.
